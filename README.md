# Gas States · Korean Practice

One app, one public marketing and study website for RushLabs’ independent Korean gas-study app. The learning content in the app is Korean. Website information and ten separately authored study guides are available in Korean and English.

This website does not contain the app question bank, signing material or private operational logs. Screenshots and the topic icon are approved presentation assets from the same Android build 6. Store availability is marked **Coming soon** until exact public availability is verified.

Build with `python3 scripts/build.py` and validate with `python3 scripts/check.py`. GitHub Pages publishes only `dist/`. No package installation or server-side runtime is required.

The browser worksheet uses fictional ideal-gas examples. It is for learning, never real equipment operation, design, filling or safety decisions. The app is not affiliated with any government, HRD Korea, Q-net or referenced institution.
